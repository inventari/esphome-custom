Use GPIO numbers (or D0–D8 on ESP8266). Use a compatible RS485 transceiver; enter a direction pin if it requires one. Verify pin suitability and wiring for your board. ESP8266 software UART may be unreliable at 115200 baud.

Writable entities can change charging behavior, disconnect communications, reset the controller, or erase statistics. They are disabled by default in Home Assistant. Review the protocol and your equipment before enabling or using them; undocumented ranges are not safety limits.

Before using your config: add wifi_ssid, wifi_password, api_encryption_key, and ota_password to your ESPHome secrets.yaml. Use a unique API key and OTA password for each device; rename those secret references in the YAML when devices share a secrets file. See ESPHome's API documentation for key generation. This page never asks for or sends your secrets.
